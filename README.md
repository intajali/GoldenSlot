
# 🎰 Golden Slot Game

A cross-platform slot game built with **Cocos Creator 3.7.3 and TypeScript**, featuring a classic **5×3 reel system**, exciting special symbols, free spins, and four jackpot reward tiers.

Designed for **Android, iOS, and Web**, Golden Slot delivers an engaging slot gaming experience with rewarding gameplay mechanics and a flexible architecture.

## ✨ Features

### 🎮 Core Gameplay

* **5×3 Reel System** — Five reels with three visible symbols per reel.
* **Base Game** — Spin the reels and win rewards through symbol combinations.
* **Special Symbols** — Dedicated symbols that activate unique gameplay mechanics.
* **Cross-Platform Support** — Built for Android, iOS, and Web platforms.

### 🔱 Special Symbols

| Symbol      | Description                                                         |
| ----------- | ------------------------------------------------------------------- |
| **Wild**    | Substitutes for eligible symbols to help form winning combinations. |
| **Scatter** | Collect six Scatter symbols to trigger the Free Spins feature.      |
| **Bonus**   | Special symbol associated with bonus gameplay mechanics.            |
| **Jackpot** | Unlocks opportunities to win jackpot rewards across multiple tiers. |

### 🎁 Free Spins

Collect **6 Scatter symbols** to trigger the Free Spins feature.

* Triggered by collecting the required number of Scatter symbols.
* Provides a dedicated bonus gameplay mode.
* Designed to add excitement and additional winning opportunities.

### 💰 Jackpot System

Golden Slot includes four jackpot reward tiers:

| Jackpot Tier | Description                 |
| ------------ | --------------------------- |
| **Mini**     | Entry-level jackpot reward. |
| **Maxi**     | Higher-tier jackpot reward. |
| **Major**    | High-value jackpot reward.  |
| **Mega**     | Top-tier jackpot reward.    |

The Jackpot symbol is associated with the jackpot reward system, giving players additional opportunities to win special rewards.

## 🚀 Getting Started

### Prerequisites

Before opening the project, ensure you have installed:

* [Cocos Creator 3.7.3](https://www.cocos.com/en/creator)
* [Git](https://git-scm.com/)
* A compatible code editor, such as [Visual Studio Code](https://code.visualstudio.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd <YOUR_PROJECT_DIRECTORY>
   ```

3. Open **Cocos Dashboard**.

4. Import or open the cloned project using **Cocos Creator 3.7.3**.

5. Wait for the project assets and dependencies to load.

6. Open the main game scene and click **Preview** to run the game.

### Build and Run

1. Open the project in Cocos Creator.
2. Open **Project → Build**.
3. Select the target platform:

   * Web Desktop or Mobile Web
   * Android
   * iOS
4. Configure the build settings.
5. Build the project and test it on the selected platform.

*Note: Android and iOS builds may require additional platform-specific tools and configuration.*

## 🎯 Gameplay Flow

1. Start the base game.
2. Spin the 5×3 reels.
3. Evaluate the resulting symbol combinations.
4. Use Wild symbols to help form eligible wins.
5. Collect 6 Scatter symbols to trigger Free Spins.
6. Encounter the Bonus symbol for bonus-related gameplay.
7. Land the Jackpot symbol for opportunities to receive Mini, Maxi, Major, or Mega jackpot rewards.
